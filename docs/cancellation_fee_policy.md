# Order Cancellation Policy

## Free cancellation window
Orders can be cancelled at no charge any time before the order enters "processing" status, which typically begins within **1 hour** of order placement. Cancellation can be done from the account order-history page.

## Cancellation after processing has started
If an order has already entered processing but has not yet shipped, it can still be cancelled, but a **15% cancellation fee** is deducted from the refund. This fee covers payment processing and fulfillment costs already incurred.

## Orders that have already shipped
Once an order has shipped, it can no longer be cancelled. The customer must instead follow the standard Refund Policy and initiate a return once the item is delivered; standard return shipping rules apply.

## How to request a cancellation
Cancellation requests are submitted either through the account order-history page or by contacting customer support with the order number. Requests are processed automatically where possible; requests made right at the processing cutoff may not always be honored if fulfillment has already begun.
